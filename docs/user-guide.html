房间布局 · 使用说明

Choose a room template, measure, arrange and compare. Everything works in your browser.

1. 选择房型与单位 / Shape and units

矩形填写整体宽深；L 形另填写右下角缺口宽深；凹位与入口房型沿用旧版 A–J 尺寸。可输入厘米、米或英尺英寸（例如 8' 6"）。未知尺寸留空，显示的比例只是预览。Calculated 是由已知关系推算的尺寸，出现冲突需复核输入。

2. 精确摆放家具 / Place furniture

点击 Furniture，再选家具。Width/Depth 是未旋转时的宽深，From left/top wall 是旋转后包围框左上角的位置。输入数字或直接拖动。R / Shift+R 旋转，方向键移动 1 cm，Shift+方向键移动 10 cm。锁定后禁止移动与旋转。Features 中可启用浴室、水槽，设置左墙窗户。

边界外或相交的物体会标示警告。未测量家具带 ~；这些检查使用示意尺寸。改变房间尺寸时，家具相对位置会跟随房间缩放，已测家具尺寸保持不变。

3. 保存与导出 / Save and export

草稿自动保存在当前浏览器。Save plan 保存命名副本；Saved plans 打开方案时，会先保存未保留的修改。JSON 可以重新导入并编辑，SVG 可以放大与分享。Export all layouts 备份所有命名方案。清理浏览数据前请先导出。在线与离线文件之间不自动同步。

Use JSON for editable backups, SVG for drawings, and Export all layouts for the complete saved library. A browser storage warning means you should export a backup manually.

4. 示例与离线 / Examples and offline

解压 ZIP 后，打开 index.html，点击 Import a plan 选择 examples 中的合成示例。单独下载的 HTML 也可直接离线打开，内置帮助不需要网络。示例不代表任何真实住宅。

macOS/Linux 校验下载：shasum -a 256 -c SHA256SUMS.txt，Windows 使用 Get-FileHash -Algorithm SHA256 对照下载页的校验和。

5. 范围 / Scope

本版支持三种正交房型，最多 100 件家具和 1000 个保存方案，导入文件不超过 25 MB。尺寸内部以厘米保存。SVG 不保证物理纸面比例；没有任意多边形、多房间、墙厚、斜墙、门扇或施工规范检查。Firefox / Safari / Chromium 的现代版本均可使用；浏览器阻止存储时仍可编辑和导出。
