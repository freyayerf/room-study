Room Study · 使用说明

1. Choose a room shape and units. Enter measured wall lengths; leave unknown values blank. Calculated dimensions are marked.
选择房型和单位，填写实测尺寸；未知值留空，推算值会标为 CALCULATED。

2. Select furniture to set width, depth and position. Drag to move; R / Shift+R rotates. Arrow keys move 1 cm, Shift+arrows 10 cm. Lock prevents moving.
选择家具输入宽、深和位置。拖动摆放，R 旋转，方向键微调，Lock 锁定。

3. Save plan keeps a named copy in this browser. Export JSON backs up editable data; SVG exports the whole drawing.
Save plan 在本浏览器保存方案；JSON 可备份并重新编辑，SVG 导出完整图纸。

4. Features can enable an optional bathroom or sink. Start over resets the draft; Undo can restore it.
Features 中可启用浴室、水槽；Start over 重置草稿，可用 Undo 撤销。

All dimensions are stored in centimeters. Preview proportions are approximate until measured. Three orthogonal templates are supported; arbitrary polygons, wall thickness and building-code checks are outside this version. / 未测量尺寸仅供示意。本版支持三种正交房型，不含任意多边形、墙厚及建筑规范校核。Data stays on this device. Export backups before clearing browser data.
