# Changelog

## 1.0.0 — 2026-10-25

- Generalized the original planner with rectangle, L-shaped and recess/entrance templates.
- Added optional bathroom and sink, preserving legacy v1 plan compatibility.
- Split geometry, validation, storage, UI and styles into maintainable source files.
- Removed private reference images and third-party font requests.
- Added standalone offline HTML, ZIP distribution and SHA-256 checksums.
- Added Chinese/English documentation, synthetic examples and MIT licensing.
- Hardened malformed imports, storage denial, item limits and zoom-independent SVG export.
- Added unit/browser coverage, verified Pages deployment and tag-based release automation.
